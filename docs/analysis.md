# ConcreteAI — Actual Model Analysis

This document summarizes the executed training run stored in `results/metrics.json`, `results/model_comparison.csv`, `results/feature_importance.csv` and `results/test_predictions.csv`. These values were generated by running the project pipeline against the 1,030-row UCI dataset, not from synthetic test fixtures.

## 1. Dataset and validation

| Item | Result |
|---|---:|
| Observations | 1,030 |
| Input features | 8 |
| Target | Concrete compressive strength (MPa) |
| Exact duplicate rows | 25 |
| Repeated feature + age profiles | 38 |
| Unique ingredient mixtures | 427 |
| Missing/non-finite values | 0 (validated during acquisition and loading) |

Rows were retained. Exact duplicates and repeated mixture-age profiles were reported rather than silently removed.

## 2. Leakage-aware split

The split grouped observations by the seven ingredient quantities, excluding age. This prevents curing ages or repeated observations from the same ingredient mix from appearing on both sides.

| Partition | Rows | Unique mixtures |
|---|---:|---:|
| Training | 815 | 341 |
| Testing | 215 | 86 |
| Total | 1,030 | 427 |

Random seed: 42. The row ratio is approximately 79.1/20.9 because GroupShuffleSplit keeps complete mixture groups intact.

## 3. Held-out test performance

| Model | MAE (MPa) | RMSE (MPa) | R² |
|---|---:|---:|---:|
| Linear Regression | 8.3832 | 10.7361 | 0.6453 |
| Random Forest | **4.0332** | **5.8886** | **0.8933** |

Random Forest reduces test MAE by about 51.9% relative to Linear Regression and reduces RMSE by about 45.2%. Its R² is higher by approximately 0.248.

## 4. Group cross-validation

Five-fold GroupKFold was run only on training data, with mixture groups kept intact.

| Model | Mean CV MAE (MPa) | CV MAE SD | Mean CV RMSE (MPa) | Mean CV R² |
|---|---:|---:|---:|---:|
| Linear Regression | 8.3408 | 0.5040 | 10.4693 | 0.5761 |
| Random Forest | **4.7932** | 0.4915 | **6.5153** | **0.8366** |

The cross-validation ranking agrees with the held-out test ranking. Random Forest's CV error is higher than its single holdout error, which is expected when evaluating multiple held-out group folds.

## 5. Overfitting check

| Model | Train MAE | Test MAE | Train R² | Test R² |
|---|---:|---:|---:|---:|
| Linear Regression | 8.2174 | 8.3832 | 0.6015 | 0.6453 |
| Random Forest | 1.2294 | 4.0332 | 0.9855 | 0.8933 |

Random Forest has a noticeable train-test gap, indicating some overfitting. However, its group cross-validation and held-out test performance remain substantially better than the Linear Regression baseline. The model should therefore be presented as the stronger predictive model for this dataset, not as a perfect or universally generalizable estimator.

Age and cement have the largest model-specific importance in this fitted Random Forest. This is not causal evidence. Correlated material quantities and the structure of the historical dataset affect importance scores.

## 7. Residual analysis

On the 215 held-out rows, Random Forest residuals are defined as actual minus predicted strength.

- Mean residual: -0.43 MPa (a small average overprediction).
- Median absolute error: 2.56 MPa.
- 90th percentile absolute error: 9.52 MPa.
- Maximum absolute error: 31.97 MPa.
- 90 rows were underpredicted and 125 were overpredicted.

The largest absolute error was an underprediction for a high-strength observation: actual 81.75 MPa versus predicted 49.78 MPa. This demonstrates why aggregate metrics alone are insufficient and why extreme predictions need engineering verification.

## 8. Linear Regression interpretation

The fitted raw-scale coefficients include cement +0.1219, water -0.1218, superplasticizer +0.4503 and age +0.1051 (MPa per one-unit increase, conditional on the other features). Coefficient values are conditional associations, not causal material laws. Correlation among mix components can change coefficient signs and magnitudes.

## 9. Conclusion

Random Forest is the better-performing model in this experiment: it lowers MAE and RMSE and achieves higher R² than the Linear Regression baseline on the group-aware holdout and grouped cross-validation. The results support the value of nonlinear ensemble learning for this dataset.

The remaining train-test gap and large worst-case residual show that the model is not suitable for safety-critical decisions. ConcreteAI is an academic prototype only. Laboratory compressive-strength testing, applicable standards and qualified engineering judgement remain necessary.
