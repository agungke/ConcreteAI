## 3. Individual reflection

Each member should answer independently:

1. What task did you personally complete?
2. Which technical decision did you contribute to, and why?
3. What problem or bug did you encounter?
4. How did you test or verify your work?
5. Which commit(s) show your contribution?
6. What would you improve if you had more time?

## 4. Peer reflection

For each teammate, describe:
- Contribution observed directly.
- Quality and timeliness of deliverables.
- Communication and collaboration.
- One constructive improvement suggestion.

Do not assign a score without an agreed rubric and peer confirmation.

## 5. Git reflection

Discuss:
- Whether work was divided into meaningful files or branches.
- Whether commits describe actual changes clearly.
- How code review and integration were handled.
- Any merge conflicts or debugging collaboration.
- Whether the final repository can be reproduced by another person.

## 6. Final confirmation

Each member should review this document and confirm that the statements about their work are accurate before submission.
